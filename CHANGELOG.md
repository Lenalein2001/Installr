# Changelog

## 0.1.9 — 2026-11-19

- Detect Opera GX installations with version numbers in their Windows display names. Show the installed version when WinGet cannot verify update availability.
- Add the standard Opera Browser as a separate catalog entry.
- Show common picks first in each category, with the remaining apps sorted alphabetically. Steam leads Games.

## 0.1.8 — 2026-11-19

- Follow Windows light, dark, and high-contrast settings and respond to changes while Installr is open.
- Show batch progress on the Windows taskbar.
- First GitHub release candidate. Includes the app library with 244 built-in packages, shared WinGet inventory and update detection, install scope selection, and a queue with cancellation and restart recovery.
